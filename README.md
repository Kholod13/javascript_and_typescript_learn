# JavaScript & TypeScript Fundamentals

Homework assignments and study materials from a JavaScript / TypeScript fundamentals course.

## Topics

- JavaScript basics: operators, program flow, data types, type conversion
- Arrays and functions
- Closures, memory management, error handling
- Object-oriented programming: objects and classes
- DOM manipulation, events and BOM
- Regular expressions, jQuery and lodash
- ES modules, destructuring, Symbol, Set, Map
- Asynchronous JavaScript: callbacks, Promises, async/await
- Node.js and a full-stack project with Fetch/AJAX
- TypeScript: basic types, interfaces, complex types, OOP
- TypeScript generics, decorators, function overloading

## Tech stack

JavaScript (ES6+), TypeScript, Node.js, HTML/CSS, jQuery, lodash

## About

A learning repository with homework solutions and notes. The code focuses on understanding concepts.
